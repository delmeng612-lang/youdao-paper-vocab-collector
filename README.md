# 有道文献生词收集器

面向文献阅读的 Chrome 和 Microsoft Edge 扩展。支持按文献归档有道查词记录，并把单词或短语导出供复习。

A Chrome and Edge extension that verifies English words and phrases against Youdao Dictionary, organizes them by research paper, and exports vocabulary as TXT for review.

**当前版本** `1.4.0` · **授权** [MIT](LICENSE) · [隐私与权限](PRIVACY.md) · [更新记录](CHANGELOG.md)

在 Zotero 阅读 PDF 时，先指定当前文献，再照常把生词或短语复制到有道词典网页查询。扩展核对查询词与有道词典的词条标题和简明释义：两者都匹配时自动加入可导出的词表；有道明确提示未找到时不收录。只有页面无法核实或该词已在其他文献收录时，才进入待确认列表。所有记录只存放在本机浏览器的扩展存储中。

## 安装

1. 在 GitHub 仓库页面点击 **Code → Download ZIP** 并解压，也可以使用 Git 克隆仓库。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，然后选中包含 `manifest.json` 的文件夹。可将扩展固定到工具栏。

本仓库提供源码安装。第一次安装无需 Node.js 或构建步骤。管理版浏览器可能限制加载解压缩的扩展。

**更新已安装版本**。先备份 JSON。在原扩展目录中替换扩展文件，再到扩展管理页点“重新加载”，然后刷新已打开的有道页面。继续使用原目录可以保留扩展 ID 和本地记录。

## 使用

1. 点击扩展图标，输入文献标题并点“开始”。之后可用下拉菜单切回此前文献。
2. 从 Zotero 复制单词或短语，在 [有道词典](https://dict.youdao.com/) 查询。支持 `youdao.com/result?word=...`、`www.youdao.com/result?word=...` 及旧版 `dict.youdao.com/w/...` 结果页。查到对应释义的词条会自动收录，拼写错误且有道提示未找到时不会收录。
3. 只有“待确认”中出现词条时才需要处理：若它已在别的文献收录，由你决定是否加入当前文献；若页面无法自动核实，可点“收录”或“忽略”。同篇重复查询不会产生重复词条。已收录词条可以删除，删除后会放入“已忽略”，再次查询不会自动出现；点“重新检查”可恢复到待确认。可随时暂停收集。若当前结果页漏收，点“检查当前有道结果页”。
4. “单词 TXT”只导出单个词；“全部词条 TXT”同时导出单词和短语。两类都可按本篇或累计导出，均为 UTF-8、每行一个词条。
5. 需要复习时，可以尝试在不背单词官网上传“累计单词 TXT”。建议先用几条单词检查当前的导入和重复处理规则。短语能否导入尚未验证，可用“全部词条 TXT”存档。[不背单词官网](https://www.bbdc.cn/)

## 备份与迁移

浏览器按扩展 ID 分开保存本地记录。把“已解压的扩展程序”移动到新路径并重新加载，可能产生新 ID，使新扩展看起来没有旧单词。移动文件夹之前，先点“备份完整记录”保存 JSON；在新位置加载扩展后点“导入备份 JSON”。导入会按文献标题合并，保留现有词条并去重。待确认和已忽略记录也保存在完整 JSON 中；TXT 只包含已确认词条。

升级到 v1.4.0 时，旧版记录会保留。打开扩展面板时，扩展会用有道网页自动复核旧待确认词条和旧版已收录词条：能确认的进入已确认；旧收录词条若无法核实，移入待确认；有道明确提示未找到的词条移出词表。跨文献重复继续等待你的决定。联网失败时保留原记录，之后再试。升级后请重新加载扩展并刷新有道网页，然后导出一份新的完整备份。

累计 TXT 会随新文献更新。是否能在不背单词中覆盖同一本自定义词书，需以你登录后看到的当前网页功能为准；若不能覆盖，可在需要时上传最新总词表并管理旧词书。

## 收词规则与常见问题

- 收录单个英文词，或最多 5 个英文词、总长不超过 80 字符的短语；词内允许连字符或撇号，词间空白会规整为单个空格。中文、带句末标点的句子和未提交的输入不会收录。自动核对依据有道当前网页的词条标题和简明释义；它不能判断文献语境中选词是否恰当。网页结构变化或缺少释义时，会放入待确认，而不会自动加入 TXT。
- 同一文献内忽略大小写去重，不合并复数或其他词形。一个词可同时保留在多篇文献中，但跨文献时先提醒你确认；累计导出只出现一次。
- 点击“开始”时若标题与已有文献相同，会继续使用原词表。切换文献后自动恢复收集。
- **网页有释义，但没看到新词**。检查是否已选择文献、是否暂停，以及词条是否在“待确认”或“已忽略”。打开的是安装前已有的结果页时，先刷新网页，再点“检查当前有道结果页”。
- **面板显示“未知操作”**。在扩展管理页重新加载，关闭旧面板，再刷新有道标签页。
- 关闭浏览器后记录仍保存在浏览器扩展存储内；卸载扩展或清除扩展数据可能删除记录。请定期导出完整 JSON 备份，并按需导出累计 TXT。

## 开发与测试

扩展使用 Manifest V3。`content.js` 从有道结果页提取匹配信号，`background.js` 管理存储、复核和导出，`popup.*` 提供扩展面板。自动测试需要 Node.js 22 或更新版本，无需安装依赖。

```sh
node --test
```

下列步骤可在安装后手动验证有道网站的实时行为。建议使用空词表测试。

1. 创建“文献 A”，查询 `imputation`、`IMPUTATION`、`in concert with` 和拼错的 `imputatoin`。已确认应只出现 `imputation` 和 `in concert with`，待确认应为空，拼错词不出现。
2. 查询中文、超过 5 个词的英文句子，或只在搜索框输入但不提交，已确认数量不应增加。
3. 创建“文献 B”，查询 `imputation`，应在待确认项看到“已在其他文献收录”，由你决定是否加入 B。累计词表中仍只出现一次。
4. 暂停后查询 `assay`，已确认不应增加。继续后点“检查当前有道结果页”，应自动收录。
5. 导出“累计单词 TXT”，应没有 `in concert with`；导出“累计全部词条 TXT”，应包含它且只出现一次。关闭并重开浏览器，检查记录仍在。
